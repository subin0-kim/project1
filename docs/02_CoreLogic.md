# 2. 핵심 로직 (Core Logic)

## 2.1 조작법 (Controls)
- **고정형 캐릭터**: 플레이어 캐릭터(무당/박수)는 이동하지 못하고 화면 정중앙에 고정되어 있습니다 ('인간 닻' 설정).
- **공격 조작**: 화면의 사방에서 밀려오는 요괴들을 향해 타이밍과 방향에 맞춰 화면을 **스와이프(Swipe)** 하여 공격(먹선 날리기)을 수행합니다.

## 2.2 스와이프 처리 (Swipe Handling)
- **입력 감지 시스템**: 화면 터치(Touch Down) 후 드래그(Drag) 시 시각적인 궤적(Trail)이 발생합니다.
- **벡터 계산**: 손을 떼는 순간(Touch Up), 시작점과 끝점 사이의 **방향 벡터(Vector2)** 를 계산합니다.
- **몬스터 방향 속성**: 모든 몬스터는 `Up/Down/Left/Right` 중 하나의 **스와이프 방향 속성**을 가집니다.
- **공격 판정 기준**: 플레이어가 스와이프하면, **스와이프 방향과 동일한 방향 속성**을 가진 몬스터만 타격 후보가 됩니다.
- **우선순위 규칙**: 후보 몬스터를 **스와이프 끝점(Touch Up 좌표)과의 거리** 기준으로 정렬하여, 끝점에 가장 가까운 1개를 타격합니다.

> 📝 **수정 사유**: 기존 "플레이어와의 거리 기준"은 항상 가장 가까운 적만 타격되어 플레이어가 원하는 적을 의도적으로 선택할 수 없었습니다. 스와이프 끝점 기준으로 변경하면 플레이어가 스와이프 방향과 길이를 조절하여 원하는 적을 조준할 수 있어 전략적 타겟팅이 가능해집니다. 스와이프 끝점은 혼불 당기기에도 동일하게 사용되어 입력 체계의 일관성이 유지됩니다.

- **다중 타격 규칙 (n-hit)**: 스킬 효과로 동시 타격 수가 `n`으로 증가한 경우, 동일 방향 후보 중 **스와이프 끝점에 가장 가까운 n개**를 동시에 타격합니다.
- **비고**: 본 판정은 방향 매칭 + 거리 우선순위를 기준으로 하며, 부채꼴/광역 각도 판정을 기본 규칙으로 사용하지 않습니다.

## 2.3 레벨업 로직 (Level Up)

### 혼불 획득
> 📝 **수정 사유**: 플레이어가 중앙에 고정되어 이동할 수 없으므로, 기존의 "이를 획득하여"(걸어다니며 수거) 방식은 구조적으로 불가능합니다. 자력 범위 기반 자동 흡수 + 스와이프 끝점 당기기 방식으로 변경합니다. 상세 메커니즘은 `honbul_system.md` 참조.

- 적을 처치하면 처치 위치에 경험치 구슬 **혼불**이 드랍됩니다.
- 혼불은 두 가지 방식으로 획득합니다:
  1. **자력 범위 자동 흡수**: 플레이어(중앙) 주변 기본 자력 반경 내 혼불이 자동으로 끌려와 흡수됩니다.
  2. **스와이프 끝점 당기기**: 스와이프가 끝나는 지점 주변의 혼불이 플레이어 방향으로 당겨집니다.
- 레벨업 선택지의 **혼불 획득 능력 증가** 옵션 선택 시 자력 반경, 끝점 당기기 반경, 혼불 이동 거리가 동시에 증가합니다.

### 로그라이크(Vampire Survivors-like) 스킬 선택
- 레벨업 시 게임이 일시 정지되며 무작위로 3개의 스킬/스탯 업그레이드 선택지가 제시됩니다.
- 플레이어는 이 중 하나를 선택하여 현재 게임 세션 동안 빌드를 구성합니다.
- 미니 보스 처치 시 보장 스킬 선택 1회가 추가 제공됩니다.

> 📝 **수정 사유**: 웨이브 간 인터미션이 제거되고 VS 타임라인 방식으로 변경되면서, 인터미션 보장 스킬 선택이 미니 보스 처치 보상으로 대체되었습니다. `wave_stage_system.md` 참조.

## 2.4 강신(Gangshin) 로직
- **신력 게이지**: 플레이어가 적을 처치하고 정화할 때마다 별도의 '신력 게이지'가 차오릅니다.
- **발동 조건**: 장착된 강신 스킬의 필요 게이지량이 충전되었을 때, **더블 탭(Double Tap)** 조작으로 강신을 발동합니다.

> 📝 **수정 사유**: 기존 "길게 누르기(Hold) 혹은 더블 탭" 두 가지 옵션에서 **더블 탭으로 단일화**하였습니다. 스와이프 입력과의 충돌을 방지하기 위함입니다.

- **강신 슬롯**: 최대 4개의 강신 스킬을 보유하며, 그 중 하나를 장착(Active)하여 사용합니다. 장착된 강신의 게이지만 충전됩니다.

> 📝 **수정 사유**: 단일 강신에서 최대 4슬롯 시스템으로 확장되었습니다. 강신 스킬마다 게이지 요구량, 효과, 패시브가 자유롭게 다르며 런 중 전투 중 자유롭게 교체 가능합니다. 상세 내용은 `gangshin_system.md` 참조.

- **발동 효과**: 장착된 강신 스킬의 효과가 발동됩니다. 발동 중에도 스와이프 입력은 유지됩니다.
