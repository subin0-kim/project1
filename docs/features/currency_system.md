# 재화 시스템 (Currency System)

## 개요
두 가지 독립 재화를 통해 **영구 성장(골드)**과 **콘텐츠 해금(영혼)**을 분리 관리한다.
- 골드: "얼마나 강한가" — 런을 거듭할수록 기본 스탯이 강해지는 성장 곡선
- 영혼: "어떤 선택지가 있는가" — 새로운 캐릭터와 스킬 해금으로 플레이 다양성 확장

---

## 골드 (Gold)

### 획득
- 인게임 전투 중 적 처치 시 드랍
- 스테이지 클리어 보상
- 결과 화면에서 광고 시청 시 2배 지급 (`07_BalanceAndMonetization.md` 참조)

### 소모처: 신당(로비) 영구 업그레이드
런과 무관하게 영구 적용되는 기본 스탯을 골드로 구매한다.

| 업그레이드 항목 | 효과 | Max Level |
|--------------|------|-----------|
| 기본 체력 증가 | +10 HP per level | 10 |
| 기본 공격력 증가 | 스와이프 데미지 배율 +% | 10 |
| 자석 반경 확장 | 혼불 획득 반경 +% | 5 |
| 강신 게이지 획득 보너스 | 처치 시 게이지 충전량 +% | 5 |
| 골드/경험치 추가 획득 | 런 내 획득량 +% | 5 |

- 업그레이드 비용은 레벨이 오를수록 증가 (상세 수치는 `07_BalanceAndMonetization.md` 참조)

---

## 영혼 (Soul)

### 획득
- 스테이지 클리어 보상 (골드보다 희귀하게 지급)
- 특정 도전 조건 달성 시 (추후 기획)

### 소모처: 콘텐츠 해금

| 해금 대상 | 비고 |
|---------|------|
| 박수 캐릭터 해금 | 무당은 기본 해금 상태 |
| 신규 스킬 해금 | 해금 후 레벨업 풀에 추가됨 |

- 신규 스킬의 구체적인 내용과 비용은 추후 기획 문서로 별도 작성

---

## 스킬 해금 정책

| 구분 | 해금 방식 | 레벨업 풀 등장 |
|------|---------|-------------|
| 기본 11종 스킬 | 게임 시작부터 전부 해금 | 즉시 등장 |
| 신규 스킬 (추후 기획) | 영혼으로 해금 | 해금 후 등장 |

- 기본 11종 스킬 목록은 `03_CharacterSettings.md` 참조

---

## 필요한 데이터 항목

**재화 저장 데이터**
- 누적 골드량
- 누적 영혼량
- 신당 업그레이드 항목별 현재 레벨
- 해금된 캐릭터 목록
- 해금된 신규 스킬 목록 (기본 11종 제외)

---

## 구현 시 주의사항

- 재화 차감 전 잔액 검증 필수 (부족 시 구매 불가 처리)
- 재화 변경 시 이벤트 발행 → UI 자동 갱신 (`06_ArchitectureAndData.md` 옵저버 패턴 원칙 준수)
- 재화 변경 시마다 즉시 저장 (유실 방지)
- 신규 스킬 해금 시 스킬 풀에 즉시 반영되어 다음 레벨업부터 선택지에 등장
