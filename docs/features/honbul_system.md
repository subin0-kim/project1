# 혼불 시스템 (Honbul System)

> 경험치 구슬 '혼불'의 드랍, 이동, 획득 전반을 정의하는 문서.
> 플레이어가 중앙 고정이라는 제약 조건을 고려하여 설계.

---

## 개요

혼불은 적 처치 시 드랍되는 경험치 구슬이다.
플레이어가 이동할 수 없으므로 혼불은 두 가지 방식으로 획득한다.

1. **기본 자력 범위**: 플레이어(중앙) 주변 일정 반경 내 혼불은 자동 흡수
2. **스와이프 끝점 당기기**: 스와이프가 끝나는 지점 주변 혼불이 플레이어 방향으로 당겨짐

---

## 혼불 드랍

- 적 처치 시 처치 위치에 혼불 드랍
- 드랍 수량은 적 종류마다 다름 (EnemyData의 혼불 드랍량 참조)
- 드랍 직후 혼불은 제자리에 정적 상태로 생성됨

---

## 혼불 획득 방식

### 1. 기본 자력 범위 (자동 흡수)
- 플레이어(중앙)를 기준으로 기본 자력 반경 내에 혼불이 진입하면 자동 흡수
- 자력 범위 내 혼불은 플레이어 방향으로 빠르게 끌려온 뒤 획득 처리
- 기본 자력 반경: **TBD** (플레이테스트 후 결정)

### 2. 스와이프 끝점 당기기
- 스와이프 입력 종료(Touch Up) 시, 스와이프 끝 지점을 기준으로 일정 반경 내 혼불이 플레이어(중앙) 방향으로 당겨짐
- 당겨진 혼불은 일정 속도로 중앙을 향해 이동, 기본 자력 범위 진입 시 자동 흡수
- 당기기 반경과 이동 속도는 혼불 당기기 스킬로 강화 가능

> **전략적 의미**: 멀리 드랍된 혼불을 수거하려면 해당 방향으로 스와이프해야 함.
> 스와이프 방향 선택에 공격 외에 혼불 수거라는 추가적인 의미가 생김.

## 혼불 소멸

- 드랍 후 일정 시간이 지나면 소멸 (획득되지 않은 혼불)
- 소멸 전 시각적 경고 연출 (예: 깜빡이기 시작)
- 소멸 시간: **TBD** (초안: 15초)

> 소멸 조건이 있어야 화면에 혼불이 무한히 쌓이지 않고,
> 플레이어가 적극적으로 스와이프를 활용해 수거해야 하는 긴장감이 유지됨.

---

## 플레이어 혼불 획득 스탯

혼불 수거 능력은 스킬이 아닌 **플레이어 스탯**으로 관리된다.
레벨업 선택지에 **"혼불 획득 능력 증가"** 옵션이 등장하며, 선택 시 아래 세 가지 스탯이 동시에 증가한다.

| 스탯 | 설명 |
|------|------|
| 자력 반경 | 플레이어 주변 자동 흡수 범위 |
| 스와이프 끝점 당기기 반경 | 스와이프 종료 지점 기준 혼불 탐색 범위 |
| 당겨지는 혼불 이동 거리 | 한 번 당겨질 때 혼불이 이동하는 거리 |

- 레벨업 수치는 `skill_balance_mvp.md` 참조
- 신당(로비) 업그레이드와 별개로 런 내에서 성장하는 스탯

## 구현 시 주의사항

- 혼불은 오브젝트 풀링으로 관리 (Instantiate / Destroy 금지)
- 스와이프 끝점 당기기: Touch Up 이벤트 발생 시 끝점 좌표 기준으로 반경 내 혼불 탐색 → 이동 상태로 전환
- 이동 중인 혼불과 정적 혼불을 상태로 구분하여 관리
- 여러 스와이프가 연속으로 발생할 경우 이미 이동 중인 혼불에 중복 당기기 적용 방지
- 혼불 소멸 타이머는 이동 상태 전환 시 리셋 (당겨지는 중엔 소멸하지 않음)
- 이벤트 기반 경험치 게이지 갱신 (`06_ArchitectureAndData.md` 원칙 준수)
