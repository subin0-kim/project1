## 난이도 곡선

### 초반 (0:00 ~ 3:00) — 적응 구간
- 손각시·창귀 위주의 단순 구성
- 스와이프 조작 익히고 혼불 수집으로 첫 레벨업 경험
- 미니 보스 1차로 첫 번째 압박 피크

### 중반 (3:00 ~ 6:00) — 다양성 증가
- 망량·산귀 추가로 처리해야 할 적의 종류 증가
- 어둑시니 첫 등장으로 시야 방해 기믹 체험
- 미니 보스 2차로 두 번째 압박 피크

### 후반 (6:00 ~ 9:00) — 복합 위협
- 두억시니(탱커)와 도깨비불(자폭) 동시 등장으로 우선순위 판단 요구
- 목귀의 뿌리 장애물로 스와이프 동선 방해
- 매구의 원거리 투사체로 패리 또는 빠른 처치 선택 압박
- 미니 보스 3차로 세 번째 압박 피크

### 클라이맥스 (9:00 ~ 10:00) — 최고 밀도
- 모든 적 조합 동시 등장
- 스킬 빌드 완성 단계, 플레이어 역량 최대 발휘 구간

### 보스전 (10:00 ~)
- 타락한 산군 등장, 일반 적 스포닝 중단 (보스 전투에 집중)
- 상세 내용은 `boss_taraghan_sangun.md` 참조

## 구현 시 주의사항

- 웨이브 타임라인은 ChapterData의 분 단위 WaveData 배열로 관리
- 미니 보스 등장 시간은 WaveCombatDirector의 타임 이벤트로 처리 (일반 스포닝과 독립적으로 관리)
- 미니 보스 등장 중 일반 적 스포닝 중단 없음
- 첫 등장 시 적별 간단한 등장 연출(이펙트) 추가 권장 — 플레이어가 새 적 등장을 인지할 수 있도록
- 보스 등장(10:00) 시 일반 적 스포닝 중단, 기존 일반 적은 페이드아웃 또는 즉시 제거 처리
