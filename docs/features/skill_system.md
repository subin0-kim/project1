# 스킬 시스템 (Skill System)

> 기존 `03_CharacterSettings.md`의 스킬 목록을 대체하는 시스템 정의 문서.
> 스킬의 종류가 아닌 **스킬이 어떻게 작동하는가**를 정의한다.

---

## 설계 원칙

- **스와이프 액션에 집중**: 스킬은 별도 버튼 UI 없이 작동한다. 플레이어 능동 입력은 스와이프와 강신 더블탭만 존재한다.
- **발동 방식으로 스킬을 분류**: 스킬의 효과가 아닌 발동 트리거 기준으로 체계를 구성한다.

---

## 발동 방식 분류 (6종)

| # | 발동 방식 | 설명 |
|---|---------|------|
| ① | 스와이프 시 확률 발동 | 스와이프 공격마다 일정 확률로 추가 효과 발생 |
| ② | 쿨타임 자동 발동 | 일정 시간마다 자동으로 효과 발생, 플레이어 입력 불필요 |
| ③ | 특정 방향 스와이프 시 발동 | 지정된 방향으로 스와이프할 때만 효과 발생 |
| ④ | 처치 시 발동 | 적을 처치하는 순간 효과 발생 |
| ⑤ | 피격 시 발동 | 플레이어가 데미지를 받는 순간 효과 발생 |
| ⑥ | 상시 패시브 | 스킬 획득 즉시 영구 적용, 별도 발동 조건 없음 |

## 기존 스킬 발동 방식 정의

### MVP 구현 대상

| 스킬 | 발동 방식 | 효과 요약 |
|------|---------|---------|
| 도깨비불 소환 | ② 쿨타임 자동 | 플레이어 주변을 궤도 비행하다 범위 내 적 감지 시 돌진 자폭. 자폭 후 쿨타임 경과 시 재소환 |
| 항마의 결계 | ⑥ 상시 패시브 | 플레이어 주변 일정 범위 내 적에게 지속 피해 (틱 데미지) |
| 재생의 굿거리 | ⑥ 상시 패시브 | 초당 고정 HP 회복 영구 적용 |
| 끈적한 묵액 | ① 스와이프 시 확률 | 스와이프마다 일정 확률로 궤적에 슬로우 자국 생성 |
| 부채살 흩뿌리기 [무당 전용] | ① 스와이프 시 확률 | 스와이프마다 일정 확률로 먹선이 부채꼴 다갈래로 퍼져 다수 적을 동시 타격. 무당 시작 시 레벨 1 보유 |

> **부채살 흩뿌리기**: 기존 "⑥ 상시 패시브(매 스와이프 항상 부채꼴 발동)" → "① 스와이프 시 확률 발동"으로 변경.
> 매 스와이프가 항상 다갈래로 퍼지면 무당의 기본 타격감이 단조로워지는 문제로, 확률 발동 + 발동 시 위력 강화 구조로 재설계. 레벨업 시 발동 확률과 갈래 수/각도가 함께 증가.
> **항마의 결계**: 기존 "결계 확장(공격 가능 반경 증가)" → "항마의 결계(降魔 結界, 범위 내 지속 피해)"로 변경.
> **혼불 당기기**는 스킬 풀에서 제거. 레벨업 선택지에 **"혼불 획득 능력 증가"** 스탯 업그레이드로 대체.
> 상세 수치는 `skill_balance_mvp.md`, 메커니즘은 `honbul_system.md` 참조.

### MVP 이후 구현 대상

| 스킬 | 발동 방식 | 효과 요약 |
|------|---------|---------|
| 먹물 폭발 | ④ 처치 시 발동 | 처치 위치에서 광역 먹물 폭발 + 주변 적 둔화 |
| 수호 장승의 진 | ⑤ 피격 시 발동 | 피격 순간 화면 내 모든 적 넉백 (쿨타임 있음) |
| 묵직한 신검 [박수 전용] | 스와이프 강화형 | 스와이프가 관통 (추후 기획) |

> 스와이프 강화형은 스와이프 자체의 동작을 바꾸는 방식으로, 별도 문서에서 기획 예정.

## 신규 스킬 컨셉

### 방향 동기화 스킬 (미명명)
- **발동 방식**: ③ 특정 방향 스와이프 시 발동
- **효과**: 해당 방향으로 스와이프하는 순간, 범위 내 적들의 방향 속성이 해당 방향으로 일괄 변경됨
- **전략적 의도**: 흩어진 방향 속성을 하나로 통일하여 연속 스와이프로 다수 적을 정리하는 순간을 만들어냄
- **미정 사항**: 효과 범위, 방향 속성 유지 시간, 발동 조건 (모든 방향에서 발동? 특정 방향만?)

> 이외 ③번 발동 방식을 활용한 스킬은 추후 추가 기획 예정.

## 구현 시 주의사항

- **버튼 UI 없음**: 모든 스킬은 자동 발동 또는 스와이프 연동. 별도 스킬 버튼 구현하지 않음
- ① 확률 발동 스킬: 확률값은 SkillData에서 관리, 레벨업마다 확률 증가 가능
- ② 쿨타임 자동 발동 스킬: 스킬 획득 즉시 첫 발동 타이머 시작
- ⑤ 피격 시 발동 스킬: 쿨타임 중 피격 시 발동하지 않음, 쿨타임 UI 표시 권장
- 스킬 발동 이벤트는 이벤트 시스템으로 관리 (`06_ArchitectureAndData.md` 원칙 준수)
- 오브젝트 풀링 필수 (도깨비불 드론, 먹물 자국 등)
