# 강화 카드 시스템 (Enhancement Card System)

> 레벨업 시 제시되는 선택지를 '강화 카드' 체계로 정의한 문서.
> 기존 `skill_system.md`의 스킬 획득 방식과 `player_stats.md`의 스탯 변화 소스를 통합한다.

---

## 개요

레벨업 또는 미니 보스 처치 시 강화 카드 3장이 제시되며, 플레이어는 이 중 1장을 선택한다.
강화 카드는 세 가지 카테고리로 구성된다.

| 카테고리 | 설명 |
|---------|------|
| 스탯 강화 카드 | 플레이어의 기본 수치를 영구 증가 |
| 스킬 강화 카드 | 스킬을 새로 획득하거나 기존 스킬을 레벨업 |
| 강신 강화 카드 | 강신 스킬을 새로 획득하거나 기존 강신 스킬을 레벨업 |

---

## 추첨 방식

### 기본 원칙
- 전체 카드 풀(스탯 + 스킬 + 강신)에서 **가중치 랜덤**으로 3장 추첨
- 카테고리 보장 없음 — 3장이 모두 같은 카테고리일 수 있음
- 최대 레벨에 도달한 스킬/스탯 카드는 풀에서 제외

### 가중치 규칙

| 카드 상태 | 가중치 배율 |
|---------|-----------|
| 미보유 스킬 / 미획득 강신 카드 | x1 (기본) |
| **보유 중인 스킬 / 강신 카드** (레벨업 가능) | x2 |
| 스탯 강화 카드 | x1 (기본) |

> **설계 의도**: 이미 보유한 스킬이 더 자주 등장하여 빌드를 깊게 강화하는 방향을 유도.
> 동시에 새로운 스킬도 등장하여 빌드 다양성을 열어둠.

### 스킬 강화 카드

스킬을 미보유 상태에서 선택하면 획득, 보유 상태에서 선택하면 레벨업.

**MVP 구현 대상**

| 카드명 | 분류 | 최대 레벨 |
|-------|------|---------|
| 도깨비불 소환 | 공격 보조 | 5 |
| 항마의 결계 | 근접 피해 | 3 |
| 재생의 굿거리 | 생존 | 3 |
| 끈적한 묵액 | 디버프 | 3 |
| 부채살 흩뿌리기 [무당 전용] | 스와이프 강화 | 3 |

> **부채살 흩뿌리기**: 무당 캐릭터 전용. 무당 시작 시 레벨 1 자동 보유.
> 레벨업 선택지에는 레벨 2부터 등장. 박수 플레이 시 카드 풀에서 제외.

**MVP 이후 구현 예정**

| 카드명 | 분류 |
|-------|------|
| 먹물 폭발 | 광역 공격 |
| 수호 장승의 진 | 방어 |
| 묵직한 신검 [박수 전용] | 스와이프 강화 |

---

### 강신 강화 카드

강신 슬롯에 새 강신 스킬을 추가하거나, 보유 중인 강신 스킬을 업그레이드.

- 빈 슬롯이 있는 경우: 선택 시 해당 강신 스킬이 빈 슬롯에 추가됨
- 슬롯이 모두 찬 경우(4개): 선택 시 기존 강신 중 하나와 교체

> 강신 슬롯 구조 및 교체 규칙 상세는 `gangshin_system.md` 참조.

## 특수 규칙

### 미니 보스 처치 보상
- 미니 보스 처치 시 **보장 강화 카드 선택 1회** 추가 제공
- 일반 레벨업 카드와 동일한 풀에서 추첨
- 레벨업으로 인한 카드 선택과 중복될 경우 Queue로 순서대로 처리

### 카드 스킵/리롤
- **리롤**: 광고 시청 시 현재 제시된 3장을 새로 추첨 (`07_BalanceAndMonetization.md` 참조)
- 스킵 기능 없음 — 반드시 1장 선택

### 캐릭터 전용 카드 필터링
- 무당 플레이 시: 박수 전용 카드 풀에서 제외
- 박수 플레이 시: 무당 전용 카드 풀에서 제외

---

## 구현 시 주의사항

- 카드 풀은 런 시작 시 캐릭터 및 해금 상태 기반으로 초기화
- 가중치 계산: 현재 보유 스킬 목록을 참조하여 보유 카드의 가중치를 x2 적용
- 최대 레벨 카드는 선택지 생성 전 풀에서 즉시 제외
- 3장 추첨 시 중복 카드 등장 방지 (같은 카드가 2장 이상 나오지 않도록)
- 카드 선택 UI는 게임 일시 정지 상태에서 표시 (Time.timeScale = 0)
- 카드 선택 완료 후 효과 즉시 적용, 다음 카드 선택 대기 중이면 Queue 소진 후 재개
- 이벤트 기반 처리 (`06_ArchitectureAndData.md` 원칙 준수)
