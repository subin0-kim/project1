# 플레이어 스탯 정의 (Player Stats)

> 플레이어 캐릭터의 모든 스탯 항목과 기본값, 변화 소스를 정의한다.
> 스탯은 강화 카드 시스템(`card_system.md`)과 연동되어 런 중 성장한다.

---

## 스탯 목록

### 기본 스탯

| 스탯 | 설명 | 무당 기본값 | 박수 기본값 |
|------|------|-----------|-----------|
| 최대 체력 | 플레이어가 받을 수 있는 최대 피해량 | 100 | 150 |
| 공격력 배율 | 스와이프 공격의 데미지 배율 | 0.8x | 1.5x |
| 방어력 | 피격 시 데미지 감소율 (%) | TBD | TBD |
| 공격 속도 | 스와이프 공격 후 다음 공격까지의 쿨타임 (초) | TBD | TBD |
| 다중 히트 | 스와이프 1회에 동시 타격 가능한 적의 수 | 1 | 1 |
| 강신 게이지 충전 배율 | 적 처치 시 강신 게이지 충전량 배율 | 1.0x | 1.0x |

> **공격 속도 설계 의도**: 스와이프를 물리적으로 아무리 빠르게 반복해도 쿨타임 내에는 공격 판정이 발생하지 않음. 연타 어뷰징 방지 및 스와이프 타이밍의 전략적 의미 부여.
> **다중 히트 설계 의도**: 기본값 1로 단일 타격. 스탯 강화 카드로 증가 가능. 신당 업그레이드 포함 여부는 미정 (초반 난이도 영향 고려).

## 스탯 변화 소스

각 스탯은 아래 소스들의 합산으로 최종값이 결정된다.

```
캐릭터 기본값
    + 신당(로비) 영구 업그레이드
    + 런 내 스탯 강화 카드 선택 누적
    + 활성화된 스킬 효과
= 최종 적용값
```

| 스탯 | 캐릭터 기본값 | 신당 업그레이드 | 스탯 강화 카드 | 스킬 효과 |
|------|------------|--------------|-------------|---------|
| 최대 체력 | ✅ | ✅ | ✅ | ✅ |
| 공격력 배율 | ✅ | ✅ | ✅ | - |
| 방어력 | ✅ | - | ✅ | - |
| 공격 속도 | ✅ | - | ✅ | - |
| 강신 게이지 충전 배율 | ✅ | ✅ | ✅ | - |
| 자력 반경 | ✅ | - | ✅ | - |
| 스와이프 끝점 당기기 반경 | ✅ | - | ✅ | - |
| 당겨지는 혼불 이동 거리 | ✅ | - | ✅ | - |
| 혼불 획득 배율 | ✅ | - | ✅ | - |
| 다중 히트 | ✅ | 미정 | ✅ | - |
| 골드 획득 배율 | ✅ | ✅ | - | - |
| 경험치 획득 배율 | ✅ | ✅ | - | - |

> 스탯 강화 카드 상세는 `card_system.md` 참조.

## 결계 반경 제거 관련

> 📝 **기획 변경**: 결계 반경(공격 가능 반경)은 플레이어 스탯에서 제거되었습니다.
> 화면에 보이는 모든 적은 타격 가능하며, 결계 원형 테두리는 순수 시각적 UI 요소로만 유지됩니다.
> 기존 스킬 "결계 확장"은 **"플레이어 주변 범위 내 적에게 틱 데미지"** 효과로 재정의되었습니다.
> 상세 수치는 `skill_balance_mvp.md` 참조.

## 구현 시 주의사항

- 모든 스탯은 `PlayerStatSystem`에서 중앙 관리
- 스탯 변경 시 이벤트 발행 → HUD 자동 갱신 (`06_ArchitectureAndData.md` 원칙 준수)
- 공격 속도(쿨타임)는 InputManager의 스와이프 판정 전 쿨타임 체크로 구현
- 다중 히트는 SwipeHandler의 타격 후보 선정 단계에서 상위 n개 선택으로 처리
