# 스탯 강화 밸런스 (Stat Balance — MVP)

> 모든 수치는 초안이며 플레이테스트 후 조정 예정.
> 스탯 강화 카드 목록 및 획득 방식은 `card_system.md` 참조.
> 플레이어 기본 스탯 정의는 `player_stats.md` 참조.
