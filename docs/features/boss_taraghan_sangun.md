## 전투 구조

### 전투 방식 — 하이브리드
- **본체 공격**: 언제든 가능. 보스의 방향 속성으로 스와이프하면 데미지
- **공격 패턴**: 중간중간 패턴 발동. 두 가지 선택지 존재:
  - **카운터**: 해당 패턴의 요구 스와이프 입력 성공 → 패턴 취소 + 보너스 데미지
  - **무시**: 패턴 미처리 → 데미지 수령, 본체 공격은 계속 가능

### 전투 흐름
```
보스 등장 연출
    ↓
1페이즈 전투 시작
(본체 공격 + 패턴 대응 반복)
    ↓
HP 50% 도달 + 진행 중 패턴 종료
    ↓
2페이즈 전환 연출 (포효 + 타락 이펙트)
    ↓
2페이즈 전투 시작
(1페이즈 패턴 강화 + 신규 패턴 추가)
    ↓
HP 0% 도달
    ↓
보스 사망 연출
    ↓
챕터 클리어
```

## 페이즈 구성

### 1페이즈 (HP 100% → 50%)

**패턴 목록**

| 패턴명 | 설명 | 카운터 입력 | 카운터 보상 |
|-------|------|-----------|-----------|
| 돌진 | 화면 바깥에서 중앙을 향해 직선 돌진. 방향 표시 후 돌진. | 보스 방향 속성 스와이프 | 패턴 취소 + 보너스 데미지 |
| 발톱 할퀴기 | 한 방향으로 거대한 발톱을 뻗음. | 해당 방향 스와이프 | 패턴 취소 + 보너스 데미지 |
| 으르렁 | 포효로 다음 패턴의 예고 시간 단축. 직접 데미지 없음. | 없음 (카운터 불가) | — |

**1페이즈 패턴 주기**: 약 8~10초마다 패턴 1회 발동 (초안)

---

### 2페이즈 (HP 50% → 0%)

2페이즈 전환 시 보스 크기 소폭 증가, 이동 속도 증가, 패턴 발동 주기 단축.

**1페이즈 패턴 변화**
- 돌진: 예고 시간 단축, 이동 속도 증가
- 발톱 할퀴기: 데미지 증가

**신규 패턴 목록**

| 패턴명 | 설명 | 카운터 입력 | 카운터 보상 |
|-------|------|-----------|-----------|
| 연속 할퀴기 | 2~3개 방향으로 연속 발톱 공격. 각 방향 순서대로 표시됨. | 표시된 방향을 순서대로 스와이프 | 전체 취소 + 보너스 데미지 |
| 광란 돌진 | 예고 시간 없이 연속 2회 빠른 돌진. | 보스 방향 속성 스와이프 (빠른 반응 요구) | 패턴 취소 + 보너스 데미지 |

**2페이즈 패턴 주기**: 약 5~7초마다 패턴 1회 발동 (초안)

## 구현 시 주의사항

- 보스 등장(10:00) 시 일반 적 스포닝 즉시 중단, 기존 일반 적 처리 방식 결정 필요 (페이드아웃 or 즉시 제거)
- 패턴 진행 중 플레이어 본체 공격은 항상 유지 (하이브리드 방식)
- 페이즈 전환은 진행 중인 패턴이 완전히 종료된 후 시작 (패턴 도중 전환 없음)
- 2페이즈 전환 연출 중 무적 처리 권장 (연출 중 데미지 수령 방지)
- 보스 방향 속성 변환 시스템은 추후 전투 시스템 재설계 시 적용 예정
