## 전투 구조

### 보스 포지셔닝
- 보스는 주로 **화면의 좌측 또는 우측**에 위치
- 평상시 화면 밖에서 대기하다가 패턴 발동 시 화면 안쪽으로 진입
- **패턴마다 좌/우 측면을 새로 골라** 양쪽에서 번갈아 등장(랜덤). 측면이 바뀌면 해당 측면의 화면 밖에서 진입하며, 보스 스프라이트는 항상 화면 중앙(플레이어)을 바라보도록 좌우 반전된다. 부하 소환·인디케이터 위치도 현재 측면을 따라간다.
- 패턴 실행 후 다시 화면 밖으로 이동하거나 화면 내에서 대기
- 화면 밖에 있을 때는 타격 불가
- 패턴 측면 랜덤화는 끌 수 있으며(끄면 홈 방향에서만 등장), 등장 연출은 항상 홈 방향에서 진입

### 보스 등장 연출
보스가 플레이어 옆에 갑자기 나타나지 않도록, 화면 밖에서 진입하는 출현 연출을 거친다.

1. **스폰**: 화면 오른쪽 밖에서 스폰(플레이어 옆에 보이지 않음). 이 동안 보스 체력바는 가려둔다.
2. **진입**: 왼쪽으로 이동해 **플레이어 오른쪽에** 멈춰 서며 출현을 알린다. 이동하는 동안 **보스 체력 UI가 0 → 100%로 점점 차오른다**.
3. **대기**: 잠깐 멈춰 출현을 각인시킨다.
4. **복귀**: 다시 화면 밖으로 이동한 뒤 일반 패턴 사이클을 시작한다.

- 연출 동안 보스는 타격 불가(무적), 체력바는 실제 HP가 아닌 연출용 채움 비율로 표시된다.
- 진입 거리/속도/정지 시간은 Inspector에서 조정 가능(초안: 플레이어 오른쪽 2.5, 이동 속도 6, 정지 1초).

### 전투 방식 — 하이브리드
- **본체 공격**: **화면 안쪽에 있을 때** 언제든 가능. 보스의 방향 속성으로 스와이프하면 데미지
- **공격 패턴**: 중간중간 패턴 발동. 두 가지 선택지 존재:
  - **카운터**: 패턴별 파훼 조건 충족 → 패턴 취소(+ 패턴에 따라 보너스 데미지). 파훼 방식은 두 종류:
    - **방향 카운터**: 요구 방향 스와이프 입력 성공 (예: 발톱 할퀴기)
    - **피해 누적 카운터**: 카운터 윈도우 동안 보스에 임계치 이상의 피해를 누적 (예: 돌진)
  - **무시**: 패턴 미처리 → 데미지 수령, 본체 공격은 계속 가능

### 전투 흐름
```
보스 등장 연출
    ↓
1페이즈 전투 시작
(본체 공격 + 패턴 대응 반복)
    ↓
HP 50% 도달 + 진행 중 패턴 종료
    ↓
2페이즈 전환 연출 (포효 + 타락 이펙트)
    ↓
2페이즈 전투 시작
(1페이즈 패턴 강화 + 신규 패턴 추가)
    ↓
HP 0% 도달
    ↓
보스 사망 연출
    ↓
챕터 클리어
```

## 페이즈 구성

### 1페이즈 (HP 100% → 50%)

**패턴 목록**

| 패턴명 | 설명 | 카운터 입력 | 카운터 보상 |
|-------|------|-----------|-----------|
| 돌진 | 화면 바깥에서 중앙을 향해 직선 돌진. | **피해 누적** — 카운터 윈도우 동안 보스에 임계치(초안 50) 이상 피해 누적 | 패턴 취소(돌진 무력화) |
| 발톱 할퀴기 | 한 방향으로 거대한 발톱을 뻗음. | 해당 방향 스와이프 | 패턴 취소 + 보너스 데미지 |
| 포효 | 산군이 하늘을 향해 포효하며 부하 호랑이 3마리 소환. 소환된 부하들을 모두 처치하기 전까지 다른 패턴 발동 없음. | 없음 (카운터 불가) | — |

> **돌진 카운터가 피해 누적인 이유**: 돌진은 보스가 화면 안에 머무는 패턴이라, 방향 카운터로 두면 평소처럼 본체를 계속 때리는 것만으로 사실상 자동 파훼되어 의미가 없다. 그래서 윈도우 동안 일정량 이상의 피해를 강제하는 방식으로 전환한다. 돌진은 카운터 방향 표시가 없으므로 **패턴 인디케이터를 띄우지 않는다**(본체 색만으로 충분). 임계치/보너스 수치는 플레이테스트 후 조정.

**1페이즈 패턴 주기**: 약 8~10초마다 패턴 1회 발동 (초안)

### 2페이즈 (HP 50% → 0%)

2페이즈 전환 시 보스 크기 소폭 증가, 이동 속도 증가, 패턴 발동 주기 단축.

**전환 연출 (구현됨)**
- HP 50% 도달 + 진행 중 패턴 종료 시, 보스가 화면 안으로 진입해 **무적 상태로 포효 연출**을 보여준 뒤 화면 밖으로 복귀하고 2페이즈 패턴을 시작한다.
- 연출 시간은 데이터(`PhaseTransitionCutsceneSeconds`, 초안 2초). 실제 포효/타락 VFX·SFX·애니메이션은 `OnPhaseTransitionStarted`/`OnPhaseTransitionEnded` 이벤트에 연결(데이터/연출 분리).
- 2페이즈 이동 속도 증가는 `BossData.PhaseMoveSpeeds`(초안 1 → 1.5배)를 진입/복귀 속도에 곱해 반영.

**1페이즈 패턴 변화 (구현됨 — 데이터)**
- 돌진: 예고 시간 단축(1→0.6초), 피해 누적 임계치 상향(50→70), 이동 속도 1.5배
- 발톱 할퀴기: 미처리/카운터 보너스 데미지 증가(15/25 → 22/35)
- 포효 강화: 부하 호랑이 5마리 소환
- 패턴 주기 단축(8~10초 → 5~7초)

**신규 패턴 (후속 슬라이스 — 미구현)**
> 연속 할퀴기·광란 돌진은 새 메커니즘이라 별도 슬라이스에서 구현한다.

**신규 패턴 목록**

| 패턴명 | 설명 | 카운터 입력 | 카운터 보상 |
|-------|------|-----------|-----------|
| 연속 할퀴기 | 2~3개 방향으로 연속 발톱 공격. **방향 시퀀스 시스템** 활용 — 각 방향이 순서대로 강조 표시되며 순서대로 스와이프해야 전체 패턴 파훼. | 표시된 방향을 순서대로 스와이프 | 전체 취소 + 보너스 데미지 |
| 광란 돌진 | 예고 시간 없이 연속 2회 빠른 돌진. | 피해 누적 (돌진과 동일 방식, 더 짧은 윈도우 + 더 높은 임계치) | 패턴 취소 |
| 포효 (강화) | 부하 호랑이 5마리 소환. 2페이즈 중 포효 패턴 발동 시 다른 패턴 동시 발동 여부 미정. | 없음 (카운터 불가) | — |

**2페이즈 패턴 주기**: 약 5~7초마다 패턴 1회 발동 (초안)

### 소환 위치

화면 밖 좌/우측에 각 3개의 스폰 포인트를 둔다 (총 6개).

| 스폰 포인트 | 위치 |
|-----------|------|
| 왼쪽 상단 | 화면 왼쪽 밖, 상단 |
| 왼쪽 중앙 | 화면 왼쪽 밖, 중앙 |
| 왼쪽 하단 | 화면 왼쪽 밖, 하단 |
| 오른쪽 상단 | 화면 오른쪽 밖, 상단 |
| 오른쪽 중앙 | 화면 오른쪽 밖, 중앙 |
| 오른쪽 하단 | 화면 오른쪽 밖, 하단 |

**소환 규칙**
- 보스가 **오른쪽**에 위치할 때 → 오른쪽 상/중/하 중 **랜덤 1개** 포인트에서 전원 소환
- 보스가 **왼쪽**에 위치할 때 → 왼쪽 상/중/하 중 **랜덤 1개** 포인트에서 전원 소환
- 같은 포효에서 소환된 부하들은 모두 동일한 포인트에서 몰아서 등장

> 보스와 같은 방향에서 부하가 쏟아지는 구조로, 플레이어는 보스 위협과 부하 처리를 같은 방향에서 동시에 대응해야 함.

> 부하 호랑이는 일반 잡몹과 동일한 방향 속성 시스템을 따르며 오브젝트 풀링으로 관리.

## 패턴 파훼 인디케이터

일반 적의 방향 표시는 캐릭터 머리 위에 고정되지만, 보스 패턴은 **공격이 준비되는 위치**에 인디케이터를 표시한다. 플레이어가 "어디서 공격이 오는지"를 직관적으로 인지하고 해당 위치를 향해 스와이프로 대응하는 구조.

> 표시 방식(색 구슬 / 화살표)은 일반 적 설정과 동일하게 환경설정에서 선택 가능. 미정.

### 일반 적 시스템과의 차이

| 구분 | 인디케이터 위치 |
|------|--------------|
| 일반 적 | 캐릭터 머리 위 고정 |
| 보스 패턴 | 공격 준비 위치에 동적 배치 (아트 기준으로 수동 조정) |

### 구현 시 주의사항
- 보스 패턴 인디케이터는 EnemyBase의 방향 속성 UI와 별개로 구현
- **인디케이터 위치는 코드에 하드코딩하지 않음**
- 각 패턴별 인디케이터 오프셋(offset) 값을 Inspector 또는 ScriptableObject에서 수동으로 조정할 수 있도록 구현 → 아트 완성 후 위치 조율 가능
- 연속 할퀴기의 경우 시퀀스 순서에 따라 인디케이터를 순차 활성화
- 오브젝트 풀링으로 관리

| 항목 | 수치 |
|------|------|
| 총 HP | 플레이테스트 후 결정 |
| 접촉 데미지 (초당) | 플레이테스트 후 결정 |
| 패턴 미처리 데미지 | 플레이테스트 후 결정 |
| 카운터 보너스 데미지 배율 | 1.5배 (초안) |
| 이동 속도 1페이즈 | 느림 |
| 이동 속도 2페이즈 | 중간 |

- 보스 등장(10:00) 시 일반 적 스포닝 즉시 중단, 기존 일반 적 처리 방식 결정 필요 (페이드아웃 or 즉시 제거)
- 보스 포지셔닝: 화면 좌/우 외부를 기본 대기 위치로, 패턴 발동 시 화면 내 진입 → 패턴 종료 후 복귀

- 패턴 진행 중 플레이어 본체 공격은 보스가 화면 안에 있을 때만 유지 (하이브리드 방식)
- 패턴 진행 중 플레이어 본체 공격은 항상 유지 (하이브리드 방식)
- 페이즈 전환은 진행 중인 패턴이 완전히 종료된 후 시작 (패턴 도중 전환 없음)

- 보스 방향 속성 변환 시스템은 추후 전투 시스템 재설계 시 적용 예정
