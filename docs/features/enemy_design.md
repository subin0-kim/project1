# 적 설계 (Enemy Design)

> 이 문서는 `04_EnemyAndMap.md`의 적 메커니즘 정의를 대체합니다.
> 맵/스테이지 구성은 `04_EnemyAndMap.md`, 웨이브 구조는 `wave_stage_system.md` 참조.

## 적 공격 방식 분류

### 기본 접촉 데미지
플레이어(중앙)와 닿아있는 동안 **매초 지속 데미지**를 입힌다.
이동 속도와 체력만 다를 뿐 메커니즘은 동일하며, 챕터 타임라인에 따라 다른 종류가 등장하여 시각적 다양성을 제공한다.
- 해당 적: 창귀, 손각시, 강철이, 망량, 산귀, 두억시니, 물귀신

### 특수 공격
별도의 공격 모션 또는 트리거를 가진다.
- 해당 적: 매구, 도깨비불, 그슨새

### 기믹 (직접 공격 없음)
플레이어에게 직접 데미지를 주지 않지만 전투를 방해한다.
- 해당 적: 어둑시니, 목귀

---

## 공통 사항

- 모든 적은 스폰 시 **Up / Down / Left / Right 중 하나의 방향 속성**이 랜덤 할당됨
- 플레이어가 해당 방향으로 스와이프하면 타격 후보가 되며, 가장 가까운 적부터 타격
- 오브젝트 풀링 필수, Instantiate / Destroy 사용 금지 (`06_ArchitectureAndData.md` 원칙 준수)

## 기본 접촉 데미지 적

스탯 기준 분류 (속도 / 체력 기준):

| 적 | 속도 | 체력 | 데미지 | 주요 등장 챕터 |
|----|------|------|--------|-------------|
| 손각시 | 빠름 | 낮음 | 낮음 | 1챕터 |
| 창귀 | 빠름 | 낮음 | 낮음 | 1챕터 |
| 망량 | 중간 | 중간 | 중간 | 1챕터 |
| 산귀 | 중간 | 중간 | 중간 | 1챕터 |
| 두억시니 | 느림 | 높음 | 높음 | 1챕터 |
| 물귀신 | 느림 | 높음 | 높음 | 3챕터 |

### 손각시
- 원한 맺힌 처녀귀신
- 창귀와 유사한 속도이나 체력이 더 낮음
- 시각적 차별점: 흰 소복 형태의 실루엣

### 창귀
- 호랑이에게 먹혀 귀신이 된 존재
- 빠른 직선 돌진, 가장 기본적인 적

### 망량
- 숲속을 떠도는 정령, 시체를 먹는 귀물
- 중간 속도로 꾸준히 접근
- 1챕터 신림(숲) 테마에 적합

### 산귀
- 산에 깃든 귀신
- 중간 속도·중간 체력
- 망량과 유사하지만 스탯 소폭 차별화

### 두억시니
- 거대한 덩치의 탱커형 귀물
- 느리지만 체력과 데미지가 높음
- 기존 3연속 콤보 기믹 제거, 순수 접촉 데미지 적으로 단순화

### 물귀신
- 물에 빠져 죽은 귀신
- 느리게 떠다니듯 접근
- 3챕터 인당수 테마에 주로 활용

## 특수 공격 적

### 매구
- **이동**: 플레이어로부터 일정 거리를 유지하며 이동 (KeepDistance 패턴)
- **공격**: 일정 쿨타임마다 원거리 투사체 발사
- **투사체**: 발사 시 투사체에 방향 속성 랜덤 할당, 해당 방향 스와이프로 패리(상쇄) 가능
- **처치 방법**: 본체 직접 타격 또는 투사체 패리하며 본체 타겟팅

### 도깨비불 (적대 개체)
- **이동**: 플레이어(중앙)를 향해 직선 이동
- **공격 트리거**: 플레이어로부터 일정 거리 이내 진입 시 팽창 시작
- **공격 흐름**: 거리 내 진입 → 팽창 연출 → N초 후 폭발 → 범위 내 즉시 데미지
- **처치 방법**: 팽창 전·중 스와이프로 처치 시 폭발 방지

### 그슨새
- **공격 흐름**:
  1. 낙하 직전 지면에 그림자 경고 표시
  2. 화면 진입 순간 Down 방향 화살표 표시
  3. 반응 시간 내 Down 스와이프로 처치 가능
  4. 처치 실패 시 착지 순간 즉시 데미지 1회 후 소멸
- **특이사항**: 반응 시간 짧아 기습 역할, 다른 적 처리 중 압박 가중

## 기믹 적

### 어둑시니
- **행동 패턴**: 스폰 → 화면 내 가시 거리까지 이동 → 잠시 대기 → 어둠 공격 → 자연 소산 → 쿨타임 후 재공격 반복
- **특이사항**: 공격력 없음, 어둠으로 시야 차단하여 다른 적 처리를 간접 방해
- **처치**: 스와이프로 처치 시 어둠 공격 완전 종료

### 목귀
- **이동**: 화면 내 자유 이동 (플레이어 위치인 중앙 제외)
- **행동**: 이동하면서 나무뿌리 장애물을 1개씩 순차 소환, 처치 전까지 반복
- **나무뿌리**: 방향 속성 랜덤 할당, 체력 보유, 플레이어 공격을 흡수
- **맵 전체 뿌리 최대 개수 제한 있음**
- **처치**: 본체 처치 시 기존 뿌리도 함께 소멸

## 미니 보스 시스템

### 개요
웨이브 타임라인 내 특정 시간 마크에 등장하는 강화형 요괴.
별도의 적 종류가 아니라 **챕터 적 풀에서 랜덤 선택한 일반 적을 강화**하여 소환한다.

### 등장 방식
- 챕터 타임라인에 정의된 시간 마크에 자동 등장 (예시: 3:00 / 6:00 / 9:00)
- 해당 챕터의 전체 적 풀(기본 접촉 + 특수 + 기믹 포함)에서 1종 랜덤 선택
- 일반 적 스포닝과 **동시 진행** (미니 보스 등장 중 일반 적 소환 중단 없음)

### 강화 사양 및 내구도 설계
- 체력 대폭 증가
- 크기 확대
- **이동 속도 느리게 고정**: 플레이어에게 닿기까지 충분한 시간을 주어 처치 기회를 보장. 단, 방심하면 조금씩 좁혀오는 압박감 유지
- **데미지 누적 넉백**: 일정량의 데미지가 누적되면 뒤로 밀려남. 집중 공격 시 거리를 유지할 수 있고, 다른 적 처리에 집중하면 다시 접근해오는 구조

> 넉백 임계값과 넉백 거리는 밸런싱 단계에서 조정.

### 처치 보상
- 보장 스킬 선택 1회 제공
- 골드 및 영혼 드랍

### 특이사항
- 기본 방향 속성 시스템 동일하게 적용 (스폰 시 랜덤 할당)
- 오브젝트 풀링으로 관리

## 필요한 데이터 항목

**기본 접촉 데미지 적 공통**
- 이름, ID
- 최대 체력
- 이동 속도
- 초당 접촉 데미지
- 처치 시 혼불 드랍량, 골드 드랍량

**도깨비불 추가 항목**
- 폭발 트리거 거리
- 팽창 후 폭발까지 대기 시간
- 폭발 데미지 및 범위

**매구 추가 항목**
- 유지 거리
- 투사체 발사 쿨타임
- 투사체 이동 속도 및 데미지

**어둑시니 추가 항목**
- 어둠 공격 전 대기 시간
- 어둠 지속 시간 (자연 소산까지)
- 재공격 쿨타임

**목귀 추가 항목**
- 뿌리 소환 쿨타임
- 뿌리 최대 체력
- 맵 전체 뿌리 최대 개수

**미니 보스 추가 항목**
- 등장 시간 마크
- 체력 강화 배율
- 크기 강화 배율
- 이동 속도 (고정 느린 값)
- 넉백 발동 데미지 임계값
- 넉백 거리
- 처치 보상 (스킬 선택 횟수, 골드량, 영혼량)
