# 적 설계 (Enemy Design)

> 이 문서는 `04_EnemyAndMap.md`의 적 메커니즘 정의를 대체합니다.
> 맵/스테이지 구성은 `04_EnemyAndMap.md`, 웨이브 구조는 `wave_stage_system.md` 참조.

---

## 적 공격 방식 분류

### 기본 접촉 데미지
플레이어(중앙)와 닿아있는 동안 **매초 지속 데미지**를 입힌다.
- 해당 적: 창귀, 두억시니

### 특수 공격
별도의 공격 모션 또는 트리거를 가진다.
- 해당 적: 매구, 도깨비불, 그슨새

### 기믹 (직접 공격 없음)
플레이어에게 직접 데미지를 주지 않지만 전투를 방해한다.
- 해당 적: 어둑시니, 목귀

---

## 공통 사항

- 모든 적은 스폰 시 **Up / Down / Left / Right 중 하나의 방향 속성**이 랜덤 할당됨
- 플레이어가 해당 방향으로 스와이프하면 타격 후보가 되며, 가장 가까운 적부터 타격
- 오브젝트 풀링 필수, Instantiate / Destroy 사용 금지 (`06_ArchitectureAndData.md` 원칙 준수)

## 요괴별 메커니즘

### 창귀 (Chang-gwi)
- **분류**: 기본 접촉 데미지
- **이동**: 플레이어(중앙)를 향해 빠른 속도로 직선 돌진
- **공격**: 플레이어와 접촉 시 지속 데미지
- **특이사항**: 없음 (가장 기본적인 적)

---

### 두억시니 (Dueoksini)
- **분류**: 기본 접촉 데미지
- **이동**: 플레이어(중앙)를 향해 느린 속도로 직선 이동
- **공격**: 플레이어와 접촉 시 지속 데미지
- **특이사항**: 체력과 방어력이 높아 처치에 많은 공격이 필요한 탱커형
- **변경 이력**: 기존 3연속 콤보 처치 기믹 제거, 일반 접촉 데미지 적으로 단순화

---

### 매구
- **분류**: 특수 공격 (원거리)
- **이동**: 플레이어로부터 일정 거리를 유지하며 이동 (KeepDistance 패턴)
- **공격**: 일정 쿨타임마다 원거리 투사체 발사
- **투사체**:
  - 발사 시 투사체에 방향 속성 랜덤 할당
  - 플레이어가 해당 방향 스와이프 시 투사체 패리(상쇄) 가능
  - 패리하지 못하면 플레이어에게 즉시 데미지
- **처치 방법**: 본체를 직접 스와이프로 처치하거나, 투사체를 패리하며 본체 타겟팅

---

### 도깨비불 (적대 개체)
- **분류**: 특수 공격 (자폭)
- **이동**: 플레이어(중앙)를 향해 직선 이동
- **공격 트리거**: 플레이어로부터 일정 거리 이내 진입 시 팽창 시작
- **공격 흐름**: 거리 내 진입 → 팽창 연출 → N초 후 폭발 → 범위 내 즉시 데미지
- **처치 방법**: 팽창 전 또는 팽창 중 스와이프로 처치 시 폭발 방지

---

### 그슨새
- **분류**: 특수 공격 (낙하)
- **이동**: 화면 위쪽 외부에서 대기 후 수직 낙하
- **공격 흐름**:
  1. 낙하 직전 지면에 그림자 경고 표시
  2. 화면 진입 순간 Down 방향 화살표 표시
  3. 플레이어가 반응 시간 내 Down 스와이프로 처치 가능
  4. 처치 실패 시 착지 순간 즉시 데미지 1회 후 소멸
- **특이사항**: 반응 시간이 짧아 높은 난이도, 다른 적 처리 중 기습 역할

---

### 어둑시니
- **분류**: 기믹 (시야 방해)
- **행동 패턴**:
  1. 스폰 후 플레이어가 볼 수 있는 화면 가장자리까지 이동
  2. 잠시 대기 (빠른 처치 시 어둠 공격을 받지 않을 수 있음)
  3. 어둠 공격 — 짙은 먹물을 뿜어 화면 일부를 가림
  4. 어둠은 시간이 지나면 자연스럽게 서서히 소산
  5. 쿨타임 후 재공격 가능 (처치 전까지 반복)
- **처치 방법**: 스와이프로 처치 시 어둠 공격 완전 종료
- **특이사항**: 공격력 없음, 시야 방해로 다른 적 처리를 간접적으로 방해

---

### 목귀 (Mok-gwi)
- **분류**: 기믹 (동선 방해)
- **이동**: 화면 내에서 자유롭게 이동 (플레이어 위치인 중앙 제외)
- **행동 패턴**:
  1. 이동하면서 나무뿌리 장애물을 한 번에 1개씩 순차적으로 소환
  2. 소환된 뿌리는 체력을 소진하기 전까지 화면에 유지
  3. 처치 전까지 뿌리 소환 반복
- **나무뿌리**:
  - 스폰 시 방향 속성 랜덤 할당
  - 체력 보유 — 플레이어 공격을 받으면 체력 감소, 소진 시 제거
  - 해당 방향 스와이프의 타격 후보가 되어 다른 적을 향한 공격을 흡수함
  - 맵 전체에 존재할 수 있는 뿌리의 최대 개수 제한 있음
- **처치 방법**: 목귀 본체를 스와이프로 처치 시 기존 뿌리도 함께 소멸
- **특이사항**: 뿌리가 공격을 흡수하여 다른 적 처치를 간접적으로 방해

## 필요한 데이터 항목

**적 공통 데이터**
- 이름, ID
- 최대 체력
- 이동 속도
- 방어력 (데미지 감소 배율)
- 처치 시 혼불 드랍 수량 및 경험치량
- 처치 시 골드 드랍량
- 방향 속성 (스폰 시 랜덤 할당)
- 이동 패턴 타입

**도깨비불 추가 데이터**
- 폭발 트리거 거리
- 팽창 후 폭발까지 대기 시간
- 폭발 데미지
- 폭발 범위

**매구 추가 데이터**
- 공격 유지 거리
- 투사체 발사 쿨타임
- 투사체 이동 속도
- 투사체 데미지

**어둑시니 추가 데이터**
- 어둠 공격 전 대기 시간
- 어둠 지속 시간 (자연 소산까지)
- 어둠 재공격 쿨타임

**목귀 추가 데이터**
- 뿌리 소환 쿨타임
- 뿌리 최대 체력
- 맵 전체 뿌리 최대 개수
