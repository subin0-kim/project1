# 방향 속성 동적 변환 시스템 (Direction Attribute Dynamic Change System)

> 기존 `02_CoreLogic.md`의 스와이프 처리에 추가되는 심화 메커니즘.
> 단일 방향 반복 공격의 단조로움을 방지하고 전략적 유연성을 부여한다.

---

## 개요

모든 적은 스폰 시 방향 속성(Up / Down / Left / Right)이 랜덤 할당된다.
플레이어가 같은 적을 동일 방향으로 반복 타격하면 해당 적의 방향 속성이 변환될 확률이 누적된다.
확률이 발동되면 방향 속성이 나머지 3방향 중 하나로 랜덤 변경된다.

---

## 상세 규칙

### 확률 누적 기준
- **적 단위 카운트**: 방향 변환 확률은 개별 적마다 독립적으로 관리된다.
- 특정 적을 **동일 방향으로 타격할 때마다** 해당 적의 카운트가 1 증가한다.
- 카운트가 쌓일수록 다음 타격 시 방향이 변환될 확률이 높아진다.

### 확률 곡선 (초안)

| 누적 타격 수 | 방향 변환 확률 |
|------------|------------|
| 1회 | 0% |
| 2회 | 10% |
| 3회 | 25% |
| 4회 | 50% |
| 5회 이상 | 75% |

> 수치는 초안이며 플레이테스트 후 조정 예정.

### 방향 변환 규칙
- 변환 시 **현재 방향을 제외한 나머지 3방향 중 랜덤**으로 새 방향 속성 할당
- 변환 후 해당 적의 카운트 **즉시 리셋** (0으로 초기화)

### 엣지 케이스

| 상황 | 처리 방식 |
|------|---------|
| 적 처치 시 | 카운트 소멸 (오브젝트 풀 반환 시 초기화) |
| 다른 방향으로 스와이프 후 다시 같은 방향으로 타격 | 카운트 유지 (리셋하지 않음) |
| n-hit 스킬로 같은 적을 1회 스와이프에 여러 번 타격 | 1회 스와이프 = 카운트 1 증가 (중복 카운트 방지) |
| 미니 보스 / 보스 | 동일 시스템 적용 (확률 곡선은 별도 조정 가능) |

---

## 시각적 피드백

### 변환 임박 연출 (변환 확률 발동 직전)
- 적 머리 위 방향 화살표가 **흔들리거나 깜빡이기 시작**
- 카운트가 높아질수록 흔들림 강도 증가
- 플레이어에게 "이 적의 방향이 곧 바뀔 수 있다"는 신호 제공

### 변환 발동 연출
- 방향 속성이 변환되는 순간 **화살표가 빠르게 회전하며 새 방향으로 전환**되는 이펙트
- 짧은 먹물 번짐 파티클 연출로 타격감 및 변환 인지 강화

---

## 필요한 데이터 항목

**적 단위 런타임 데이터**
- 현재 누적 타격 카운트
- 현재 방향 속성

**시스템 설정 데이터**
- 카운트별 방향 변환 확률 테이블
- 변환 임박 연출 시작 카운트 임계값
- 보스/미니 보스 전용 확률 테이블 (선택적)

---

## 구현 시 주의사항

- 카운트는 EnemyBase에 런타임 변수로 추가, 오브젝트 풀 반환 시 반드시 초기화
- n-hit 판정 시 같은 스와이프에서 동일 적에 대한 카운트 증가는 1회로 제한
- 방향 변환은 즉시 적용 (진행 중인 이동 패턴 유지, 다음 타격 판정부터 새 방향 적용)
- 변환 연출은 이벤트 발행 후 UI/VFX 레이어에서 처리 (`06_ArchitectureAndData.md` 원칙 준수)
- 화살표 흔들림 연출은 카운트 임계값 도달 시 이벤트로 트리거, 매 프레임 체크 금지
