# 강신(Gangshin) 시스템

## 개요
강신은 신력 게이지를 충전하여 발동하는 필살기 시스템.
런 중 레벨업으로 강신 스킬을 추가 획득하고 전투 중 자유롭게 교체하며 전략적으로 활용한다.
각 강신 스킬은 타입 분류 없이 개별 수치(게이지 요구량, 패시브, 발동 효과)를 자유롭게 가진다.

---

## 강신 슬롯 구조

- 최대 보유 수: **4개** (캐릭터 기본 강신 1개 + 레벨업으로 최대 3개 추가)
- 4개 슬롯 중 하나를 **장착(Active)** 상태로 지정
- 전투 중 언제든지 자유롭게 교체 가능 (UI 탭으로 교체)

---

## 신력 게이지

- **장착된 강신의 게이지만 충전**됨
- 비장착 강신의 게이지는 일시정지 상태로 유지 (교체 시 이전 수치 복원)
- 게이지 충전량: 적 처치 시 기본 1~2% (강신 스킬별 충전 배율로 조정)
- 필요 게이지량을 채우면 발동 가능 상태
- 필요 게이지량이 0인 강신은 게이지 없이 패시브만 제공 (게이지 UI 숨김)

---

## 발동 조작

- **더블 탭(Double Tap)**: 탭 간격 300ms 이하를 더블 탭으로 인식
- 발동 중에도 스와이프 입력 유지 가능
- 발동 후 게이지 0으로 초기화

---

## 캐릭터 기본 강신

캐릭터 선택 시 슬롯 1에 기본 강신이 장착된 상태로 시작한다.

| 캐릭터 | 기본 강신 | 효과 |
|--------|---------|------|
| 무당 | 살풀이 검무 | 하얀 소창이 화면 전체를 휩쓸어 모든 적에게 막대한 피해 |
| 박수 | 파천의 징 | 먹물 파동이 중앙에서 바깥으로 뻗어나가며 전체 피해 + 기절(Stun) |

---

## 레벨업 연동

- 강신 스킬은 레벨업 선택지 풀에 포함되어 등장
- 선택 시 빈 슬롯에 자동 추가
- 슬롯이 모두 찬 경우(4개): 기존 강신 중 하나를 선택해 교체
- 인터미션 보장 스킬 선택에도 강신 카드가 등장할 수 있음

---

## UI 정의

- **HUD 내 강신 슬롯 표시**: 보유한 강신 목록을 아이콘으로 표시 (최대 4개)
- **장착된 강신**: 게이지 바 + 아이콘 강조 표시
- **비장착 강신**: 아이콘만 표시 (탭으로 교체)
- **필요 게이지량 0인 강신 장착 시**: 게이지 바 숨김, 패시브 효과 아이콘 표시
- UI 위치: 기존 HUD 가장자리 배치 원칙 준수 (`05_ScreenStructure.md` 참조)

---

## 필요한 데이터 항목

**강신 스킬 데이터 (강신 1개 단위)**
- 이름, 설명, 아이콘
- 발동에 필요한 게이지량 (0이면 패시브 전용)
- 게이지 충전 배율 (기본 충전량 대비)
- 발동 데미지
- 발동 효과 지속시간
- 패시브 효과 (없을 수 있음 — 장착 중 항상 적용)

**강신 슬롯 상태 데이터 (런 중 관리)**
- 슬롯별 현재 게이지 수치 (교체 시 보존)
- 현재 장착 중인 슬롯 인덱스

---

## 구현 시 주의사항

- **더블 탭 감지**는 InputManager에서 처리
  - 드래그 거리 임계값(예: 20px) 이상이면 스와이프, 미만이면 탭으로 분류하여 입력 충돌 방지
- **게이지 충전 중단/복원**: 교체 시 현재 장착 강신의 게이지 수치를 저장, 새로 장착한 강신의 이전 수치 복원
- **패시브 효과**: 장착 시 활성화, 교체/해제 시 즉시 비활성화
- **이벤트 기반 UI 갱신** — 게이지 변경, 슬롯 교체, 발동 시 각각 이벤트 발행 (`06_ArchitectureAndData.md` 원칙 준수)
- **발동 중 입력**: 강신 발동 애니메이션 재생 중에도 스와이프 입력 유지
