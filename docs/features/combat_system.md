# 전투 시스템 (Combat System)

> 묵선(墨線)의 인게임 전투 전반을 정의하는 문서.
> 세부 시스템은 각 전용 문서를 참조한다.

---

## 1. 기본 전투 구조

- 플레이어 캐릭터는 화면 중앙에 고정 (이동 불가, '인간 닻' 설정)
- 사방에서 접근하는 적을 스와이프로 공격하여 정화
- 모든 적은 스폰 시 방향 속성(Up / Down / Left / Right)이 랜덤 할당됨
- 플레이어가 해당 방향으로 스와이프해야 타격 가능

---

## 2. 스와이프 공격

### 입력 처리
- Touch Down 후 드래그 시 붓 궤적(Trail) 시각 효과 발생
- Touch Up 시점에 시작점-끝점 사이의 방향 벡터 계산 → 공격 방향 확정

### 타겟팅
- 스와이프 방향과 일치하는 방향 속성의 적들이 타격 후보
- 후보 중 **스와이프 끝점(Touch Up 좌표)에 가장 가까운 적**을 우선 타격
- 다중 히트 스탯이 n일 경우 끝점에서 가까운 순서대로 n개 동시 타격
- 화면에 보이는 모든 적은 타격 가능 (별도 사거리 제한 없음)

### 공격 속도 (쿨타임)
- 스와이프 공격 후 일정 쿨타임 내 재입력 시 공격 판정 발생하지 않음
- 물리적 연타 어뷰징 방지 및 스와이프 타이밍에 전략적 의미 부여
- 쿨타임 수치는 공격 속도 스탯으로 감소 가능 (`stat_balance_mvp.md` 참조)

---

## 3. 방향 속성 시각화 — 색상 시스템

### 기본 색상 매핑 (디폴트)

| 방향 | 색상 | 연상 |
|------|------|------|
| Up | 청(靑) — 청록색 | 하늘 |
| Down | 황(黃) — 황금색 | 땅 |
| Left | 적(赤) — 붉은색 | — |
| Right | 녹(綠) — 초록색 | — |

> 한국 전통 오방색(五方色)에서 흑·백을 제외하고 게임 테마에 맞게 재구성.
> 유저가 환경설정에서 방향↔색상 매핑을 자유롭게 변경 가능.

### 표시 방식

두 가지 표시 방식을 동시에 구현하며, 환경설정에서 선택 가능.

**A. 외곽선 글로우 (기본)**
- 적 스프라이트의 테두리가 방향 속성 색상으로 발광
- 수묵화 스타일과 자연스럽게 어우러지는 방식

**B. 색 오브 (구슬)**
- 적 머리 위에 작은 색 구슬이 떠있음
- 기존 화살표 UI 자리에 위치하여 직관적 인식

### 접근성 옵션
- 색맹·색약 유저를 위해 **화살표 병행 표시** 옵션 제공
- 환경설정에서 활성화 가능
- 색상 표시와 화살표 표시는 독립적으로 설정

---

## 4. 방향 속성 동적 변환

- 같은 적을 동일 방향으로 반복 타격 시 방향이 변환될 확률이 누적
- 변환 임박 시 색상/구슬이 흔들리거나 깜빡이는 시각 피드백 제공
- 변환 발동 시 새 방향에 해당하는 색상으로 즉시 전환되는 이펙트

> 상세 규칙 및 확률 수치는 `direction_dynamic_system.md` 참조.

---

## 5. 방향 시퀀스 시스템

### 개요
특정 대상(보스, 추후 기획될 기믹 몹)이 고유한 방향 시퀀스를 가지며, 플레이어가 지정된 방향을 순서대로 스와이프해야 HP 또는 패턴 파훼 효과가 발동된다.

### 작동 방식
- 대상은 스폰 또는 패턴 발동 시 고유 방향 시퀀스를 가짐 (예: ↓ → ←)
- 현재 타격해야 할 방향만 색상/하이라이트로 강조 표시
- 시퀀스 3개 초과 시 4번째부터 `...`으로 가려지며, 성공 타격마다 한 칸씩 앞으로 당겨짐
- 순서에 맞는 방향으로 스와이프 성공 시 다음 시퀀스로 진행
- 잘못된 방향 스와이프 시: 시퀀스 초기화 또는 패널티 (미정)

### 동시 적용 원칙
- 시퀀스 진행 중 스와이프는 시퀀스 대상에게도, **일반 적에게도 동시에 타격 판정** 발생
- 플레이어가 시퀀스를 입력하면서 동시에 주변 잡몹도 처리 가능
- 단, 타겟팅 우선순위는 기존 스와이프 끝점 기준 유지

### 적용 대상

| 대상 | 적용 | 비고 |
|------|------|------|
| 일반 잡몹 | ❌ | 다수 등장 시 화면 과부하 우려 |
| 기믹 몹 (현재 기획분) | ❌ | 추후 신규 기획 시 활용 예정 |
| 미니 보스 | ❌ | 현재 넉백 + 높은 체력으로 충분 |
| 보스 | ✅ | 패턴 파훼 메커니즘으로 활용 |
| 추후 기획 기믹 몹 | 예정 | 단일 대상 등장 시 적합 |

### 보스 활용 예시
- **연속 할퀴기 (2페이즈)**: 2~3개 방향이 시퀀스로 표시되며 순서대로 스와이프해야 패턴 파훼
- 상세 패턴은 `boss_taraghan_sangun.md` 참조

---

### 피격 방식
- 접촉 데미지 적: 플레이어와 닿아있는 동안 **매초 지속 데미지**
- 특수 공격 적: 각 적의 고유 공격 패턴에 따라 즉시 또는 범위 데미지

### 방어력
- 피격 시 방어력 스탯만큼 데미지 감소
- 방어력 상한선 설정 필요 (과도한 무적 방지)

### 사망 조건
- 체력(HP)이 0이 되면 게임 오버

---

## 6. 강신 시스템

- 신력 게이지 충전 후 더블 탭(Double Tap)으로 발동
- 발동 중에도 스와이프 입력 유지 가능
- 최대 4슬롯, 장착된 강신 스킬의 게이지만 충전

> 상세 규칙 및 슬롯 구조는 `gangshin_system.md` 참조.

---

## 7. 혼불 수거

- 적 처치 시 처치 위치에 혼불 드랍
- 스와이프 끝점 주변 혼불이 플레이어 방향으로 당겨짐
- 기본 자력 범위 내 혼불은 자동 흡수

> 상세 메커니즘은 `honbul_system.md` 참조.

---

## 8. 필요한 데이터 항목

**색상 시스템 설정 데이터**
- 방향별 기본 색상값 (Up/Down/Left/Right → Color)
- 표시 방식 선택 (글로우 / 오브 / 둘 다)
- 화살표 병행 표시 여부
- 유저 커스텀 색상 매핑 (환경설정 저장)

---

## 9. 구현 시 주의사항

- 방향 속성 색상은 EnemyBase에서 스폰 시 할당, 렌더러에 즉시 반영
- 글로우 효과는 URP/Post-Processing 또는 Shader Graph로 구현 권장
- 색 오브는 오브젝트 풀링으로 관리
- 동적 변환 발생 시 색상 전환 이펙트는 이벤트 발행 후 VFX 레이어에서 처리
- 표시 방식 변경은 런타임에 즉시 반영되어야 함 (인게임 중 설정 변경 가능)
- 색상 매핑 커스터마이징 데이터는 SaveData에 포함하여 영구 저장
- 이벤트 기반 처리 (`06_ArchitectureAndData.md` 원칙 준수)
