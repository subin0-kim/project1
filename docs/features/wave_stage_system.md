# 웨이브 & 스테이지 시스템 (Wave & Stage System)

## 개요
- 한 런(Run)의 총 목표 시간: **약 15분**
  - 일반 전투 구간: 0:00 ~ 10:00 (10분)
  - 메인 보스 전투: 10:00 ~ 15:00 (3~5분)
- 3개 챕터(신림 / 태백산 천제단 / 인당수)는 선택 가능한 독립 맵으로 제공 (난이도·테마 차별화)

---

## 스포닝 방식

Vampire Survivors 스타일의 **타임라인 기반 연속 스포닝**을 사용한다.

- 1분 단위로 웨이브가 전환되며, 각 웨이브는 등장 적 종류·최소 수량·소환 간격을 정의
- 웨이브 전환은 시간 경과에 따라 자동으로 이루어짐 (클리어 조건 없음)
- 최소 수량이 충족되지 않으면 채울 때까지 계속 소환, 충족된 경우 각 적 타입을 1마리씩 추가 소환
- 적은 화면 바깥에서 소환됨
- 시간이 지날수록 적의 밀도·종류·속도가 증가하여 난이도가 상승

## 미니 보스 시스템

### 등장 방식
- **특정 시간 마크(3:00 / 6:00 / 9:00)** 에 자동 등장
- 해당 챕터의 적 풀에서 1종 랜덤 선택 후 미니 보스 사양으로 강화하여 소환
- 미니 보스 등장 중 일반 적 스포닝 **계속 유지** (동시 진행)

### 강화 사양
- 체력 대폭 증가
- 크기 확대
- (선택적) 이동 속도, 공격 빈도 등 추가 강화

### 처치 보상
- **보장 스킬 선택 1회** 제공 (기존 인터미션 보장 스킬 선택을 대체)
- **골드 및 영혼 드랍**

### 특이사항
- 미니 보스는 오브젝트 풀링으로 관리
- 일반 적과 동일한 방향 속성 시스템 사용 (스폰 시 랜덤 할당)

## 메인 보스

- 10:00에 자동 등장, 별도 등장 연출 시퀀스 재생
- 등장 시 보스 전용 HP 게이지 상단 활성화 (`05_ScreenStructure.md` 참조)
- 보스 처치 = 스테이지 클리어 → 결과 화면으로 전환
- 보스 상세 설계는 `boss_taraghan_sangun.md` 참조

---

## 레벨업 (스킬 선택)

- 전투 중 혼불(경험치 구슬) 획득으로 경험치 게이지 충전
- 레벨업 시 게임 일시 정지 후 스킬 선택 UI 표시 (기존 시스템 유지)
- 미니 보스 처치 시 보장 스킬 선택 1회 추가 제공
- 여러 스킬 선택이 대기 중인 경우 Queue로 순서대로 처리

## 구현 시 주의사항

- 웨이브 전환은 타이머 기반, 클리어 조건 없음
- 미니 보스는 일반 적과 별도 소환 트리거로 관리 (WaveCombatDirector 내 타임 이벤트)
- 스킬 선택이 여러 번 대기 중인 경우 Queue로 순서대로 소진
- 보스 등장 시 별도 시퀀스 코루틴으로 분리, 보스 등장 연출 중에도 일반 스포닝 중단 여부는 연출 기획에 따름
- Instantiate / Destroy 금지 — 오브젝트 풀링 필수 (`06_ArchitectureAndData.md` 원칙 준수)
