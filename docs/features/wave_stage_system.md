# 웨이브 & 스테이지 시스템 (Wave & Stage System)

## 개요
- 한 런(Run)은 약 10분 내외로 종료되도록 설계
- 타깃 플레이어: 쉬는 시간(10분 내외)에 가볍게 즐기는 직장인/학생
- 3개 챕터(신림 / 태백산 천제단 / 인당수)는 선택 가능한 독립 맵으로 제공 (난이도·테마 차별화)
- 런 구조: Wave 1 → 인터미션 → Wave 2 → 인터미션 → Wave 3 → 보스 등장 → 보스 처치 = 클리어

---

## 런 구조 상세

### 웨이브 클리어 조건
- 각 웨이브는 사전에 설계된 적 구성(Enemy Pool)을 순차적으로 소환
- 해당 웨이브의 모든 적을 처치하면 웨이브 클리어
- 시간 제한 없음 (목표 소요 시간은 밸런싱 기준으로만 사용)

### 목표 소요 시간

| 구간 | 목표 시간 | 내용 |
|------|----------|------|
| Wave 1 | ~2분 | 창귀 위주, 기본 조작 적응 구간 |
| 인터미션 1 | 30초 | 클리어 연출 + 보장 스킬 선택 1회 |
| Wave 2 | ~3분 | 요괴 종류 다양화, 기믹 요괴 등장 시작 |
| 인터미션 2 | 30초 | 클리어 연출 + 보장 스킬 선택 1회 |
| Wave 3 | ~3분 | 고밀도 + 특수 요괴 복합 등장, 최대 압박 |
| 보스 등장 연출 | ~30초 | 컷신 / 이펙트 시퀀스 |
| 보스 전투 | ~1분 | 보스 처치 = 스테이지 클리어 |
| **총합** | **~10분** | |

### 인터미션 상세
- 웨이브 클리어 직후 전투 일시 정지
- **보장 스킬 선택 1회** 제공 (기존 레벨업 스킬 선택 UI 동일하게 사용)
- 레벨업으로 인한 스킬 선택과 중첩될 경우 순서대로 처리 (큐잉)
- 스킬 선택 완료 후 다음 웨이브 예고 연출 재생 → 전투 재개

### 보스 등장 조건
- Wave 3 클리어 직후 보스 등장 시퀀스 자동 시작
- 보스 HP 게이지 상단 활성화 (`05_ScreenStructure.md` 참조)
- 보스 처치 = 스테이지 클리어 (결과 화면으로 전환)

## 챕터별 구성

| 챕터 | 배경 | 보스 | 특징 |
|------|------|------|------|
| 1장 - 신림 | 당산나무 숲 | 타락한 산군 | 기본 난이도, 지상형 요괴 위주 |
| 2장 - 천제단 | 구름 위 하늘 제단 | 부정한 뇌성조 | 공중 낙하 요괴 다수 등장 |
| 3장 - 인당수 | 침몰하는 목선 위 | 흑연의 이무기 | 수중·소용돌이 기믹 |

- 챕터 상세 적 구성은 `04_EnemyAndMap.md` 참조
- 각 챕터의 Enemy Pool은 챕터별로 독립 관리

## 필요한 데이터 항목

**웨이브 데이터 (웨이브 1개 단위)**
- 소환할 적 목록 (적 종류, 수량, 웨이브 시작 후 등장 딜레이)
- 적 소환 간격

**챕터 데이터**
- 챕터 이름
- 웨이브 데이터 목록 (3개 고정)
- 보스 데이터 참조

---

## 구현 시 주의사항

- 웨이브 클리어 판정: 현재 활성 적 수 == 0 이고 소환 큐가 비었을 때 클리어 이벤트 발행
- 인터미션 중 스킬 선택이 여러 번 대기 중인 경우 Queue로 관리, 순서대로 소진
- 보스 등장은 일반 웨이브와 분리된 별도 시퀀스로 처리, 보스 등장 중 일반 적 스포닝 완전 중단
- Instantiate / Destroy 금지 — 오브젝트 풀링 필수 (`06_ArchitectureAndData.md` 원칙 준수)
